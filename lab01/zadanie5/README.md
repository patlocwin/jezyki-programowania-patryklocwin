# Zadanie 2 z listy

## Treść zadania
Stwórz program, który generuje losowe liczby i dodaje je do listy typu ArrayList i LinkedList. Następnie przetestuj, jak długo trwa dodawanie, usuwanie i przeszukiwanie elementów w obu listach.

## Uruchomienie
Główna klasa programu to `lab01.zadanie5.Main`.

Za pomocą Gradle (z katalogu głównego):
```bash
./gradlew run-lab01-zadanie5
```

Bezpośrednio przez Java:
```bash
javac -d out lab01/zadanie5/*.java
java -cp out lab01.zadanie5.Main
```
